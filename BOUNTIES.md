# Bounties

Some issues carry a fixed bounty for an accepted pull request.

| Item | Rule |
|---|---|
| Amounts | Stated on each issue. **Pool and per-issue amounts: to be set before launch.** |
| Eligibility | Contributor has signed the CLA (or is covered by a CCLA) and is not barred by law or sanctions from receiving payment |
| Claiming | Comment on the issue to claim; a maintainer assigns it. Unassigned work is not eligible |
| Acceptance | Paid on merge, when the pull request meets the issue's acceptance tests and passes CI |
| One payer | Paid by Element Ventures (Canada) Ltd. to the CLA signatory |
| Disputes | Decided by the lead maintainer |

Bounties pay for resolved issues only — never for time, seats or access.
