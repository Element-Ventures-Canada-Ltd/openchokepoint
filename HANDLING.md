# Handling

Every file in this repository is public and carries the marking `Handling: Unclassified — public`.

| Allowed | Not allowed |
|---|---|
| Synthetic (fictional) records, clearly marked `synthetic: true` | Real organizations' non-public information |
| Public, citable sources | Personal information |
| Schema, code and documentation | Confidential, proprietary or Government-designated confidential information |
| | Export-controlled technical data |
| | Any material marked above "Unclassified — public" |

CI enforces the marking and scans for classification markings and credentials. Reviewers remain responsible for judgment.
If you think something sensitive was committed, report it privately (see SECURITY.md); do not open a public issue.
