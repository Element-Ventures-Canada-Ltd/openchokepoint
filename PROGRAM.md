# Open technical-community programme

**Window:** from launch to 31 March 2027.
**Goal:** a community-reviewed open grammar for supply-chain dependency registries, with a validator and a worked first use case.
**Programme partner:** _[to be confirmed — named only with the partner's written consent]_

## First use case: space turbopump supply chain

Map the supply chain behind liquid-rocket-engine turbopumps — materials, bearings and seals, machining, test — as a fully synthetic example that exercises every type in the schema. It is the reference that later real-data work will follow.

## How work is organized

| Track | What contributors do |
|---|---|
| Schema | Propose and review types, properties and validation rules |
| Tooling | Validator features, converters (CSV, JSON), test coverage |
| Examples | Synthetic worked examples and documentation |

Issues are labelled by track. Bounty issues carry the `bounty` label and a tier label. Accepted work is recorded in the deferred ledger ([BOUNTIES.md](BOUNTIES.md), [LEDGER.md](LEDGER.md)) and paid only after a Funding Event.

## Timeline

| Phase | Window | Output |
|---|---|---|

| Launch | On public release | Open issues, bounties posted |
| Close | 31 March 2027 | Tagged v1.0 of the grammar and validator |
